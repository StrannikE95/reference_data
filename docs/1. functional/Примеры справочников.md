# Примеры справочников для проверки загрузки

Десять опубликованных наборов из предметной области РЕОН: объекты недвижимости, права, земля, адрес и территориальное деление Москвы. Наборы подобраны как испытательные входы, а не как решение, что все они входят в модуль.

Проверено 22.10.2026: страницы XML-схем, CSV и ZIP ГАР отвечают. Прямой адрес экспорта data.mos.ru без браузера отдаёт оболочку сайта, поэтому для портала Москвы указана карточка набора, а не ссылка «скачать файл».

## 1. Назначение здания

Один плоский список пар «код — наименование».

| | |
|---|---|
| Сложность | Одна таблица |
| Откуда брать | Открыть страницу и скопировать список: [AssignationBuilding / dAssBuilding](http://xmlblog.ru/uzly/375655/) |
| Предыдущие версии | Тот же перечень в составе более ранней схемы технического плана: [TP_v06](http://xmlblog.ru/uzly/377704/). Официальные схемы разных лет лежат в разделе [XML-схемы Росреестра](https://rosreestr.gov.ru/activity/okazanie-gosudarstvennykh-uslug/vedenie-egrn/xml-skhemy/) |
| Формат | HTML, пары «12-значный код / наименование» |
| Как получать | Копирование со страницы |

Пример значений: `204001000000` нежилое, `204003000000` многоквартирный дом.

## 5. ОКТМО

Иерархия территорий: субъект, муниципальное образование, населённый пункт. К адресной и земельной части РЕОН относится как код территории.

| | |
|---|---|
| Сложность | Одна таблица с иерархией |
| Откуда брать | Файл CSV: [oktmo.csv](https://classifikators.ru/assets/downloads/oktmo/oktmo.csv). Страница файла: [classifikators.ru/oktmo](https://classifikators.ru/oktmo) |
| Предыдущие версии | Официальные срезы публикует Росстат, каждый файл — состояние классификатора на дату: [карточка 7708234640-oktmo](https://rosstat.gov.ru/opendata/7708234640-oktmo) |
| Формат | CSV, поля в кавычках, разделитель «;» |
| Как получать | Скачивание файла. CSV по ссылке выше — перепубликация; юридический источник версий — карточка Росстата |

## 7. ГАР: адресные объекты и связи между ними

Несколько таблиц в одном архиве. Уровень адреса ссылается на родительский объект: регион, населённый пункт, улица, дом, помещение. Отдельные файлы задают административную иерархию, муниципальную иерархию и типы параметров.

| | |
|---|---|
| Сложность | Несколько связанных таблиц |
| Откуда брать | Описание состава файлов, небольшой ZIP: [structure-12032021.zip](https://data.nalog.ru/opendata/7707329152-fias/structure-12032021.zip). Карточка набора: [7707329152-fias](https://www.nalog.gov.ru/opendata/7707329152-fias/) |
| Предыдущие версии | Полные еженедельные срезы. Проверенные файлы: [16.10.2026](https://fias.nalog.ru/opendata/7707329152-fias/data-16102026-structure-20191024.zip), [13.10.2026](https://fias.nalog.ru/opendata/7707329152-fias/data-13102026-structure-20191024.zip), [09.10.2026](https://fias.nalog.ru/opendata/7707329152-fias/data-09102026-structure-20191024.zip). Каждый полный срез — около 57 ГБ |
| Формат | ZIP, внутри XML |
| Как получать | Скачивание архива. Для проверки разбора достаточно ZIP со структурой. Полный срез нужен только для нагрузки |

Сама адресная запись в модуль справочников целиком не входит. Архив здесь — пример связанных XML-таблиц и смены версии.

|---|---|

## 9. Территориальные единицы Москвы

Две связанные таблицы одного классификатора. Первая — округа, районы и поселения. Вторая — виды этих единиц (`02` административный округ, `03` район). Строка района ссылается на округ первыми цифрами кода и на вид единицы отдельным полем. В строке также лежит код ОКАТО.

| | |
|---|---|
| Сложность | Несколько связанных таблиц |
| Откуда брать | Устройство и правила кодирования: [ОМК ТЕ, приложение 7](https://base.garant.ru/70386658/1a3794674ba91fb6f13d1885dca9f9e1/). Образец строк обоих разделов: [пример записи](https://base.garant.ru/70386658/2303325ae84a54ba223840316a0fb8f7/). Карточка набора на портале Москвы, экспорт из интерфейса: [ОМК 002-2013, раздел 1](https://data.mos.ru/opendata/7710168515-obshchemoskovskiy-klassifikator-territorialnyh-edinits-moskvy-omk-002-2013-razdel-1) |
| Предыдущие версии | Редакции постановления 294-ПП от 27.05.2015 и 04.10.2017 перечислены на [странице постановления](https://base.garant.ru/70386658/) |
| Формат | HTML-описание и HTML-таблица образца. Портал отдаёт набор как JSON и предлагает экспорт; прямая ссылка вида `/datasets/export/...` без сессии браузера скачивает не файл, а страницу сайта |
| Как получать | Копирование образца со страницы ГАРАНТ. Полный набор — кнопкой экспорта на карточке data.mos.ru |

## 10. Улицы Москвы

Два раздела одного классификатора: улицы и виды улиц. Улица связана с районом из ОМК ТЕ. Код улицы — шесть знаков, полное и краткое наименование, транслитерация, код вида.

| | |
|---|---|
| Сложность | Несколько связанных таблиц |
| Откуда брать | Состав полей и связь разделов: [ОМК УМ, приложение 3](https://base.garant.ru/70386658/3e22e51c74db8e0b182fad67b502e640/) |
| Предыдущие версии | Срезы открытых данных до 17.06.2019 перечислены на сохранённой карточке: [архив data.mos.ru, набор 2044](https://web.archive.org/web/20190804071401/https://data.mos.ru/classifier/2044). Редакции постановления — на [странице 294-ПП](https://base.garant.ru/70386658/) |
| Формат | HTML-описание структуры. Карточка открытых данных объявляла экспорт JSON и CSV |
| Как получать | Структура и правила — копированием со страницы ГАРАНТ. Файлы значений — с карточки открытых данных; в архиве виден перечень версий, не сами файлы |

Полный перечень улиц на странице постановления не опубликован: там описан состав классификатора. Для прогона загрузки значений нужен файл с портала открытых данных.
