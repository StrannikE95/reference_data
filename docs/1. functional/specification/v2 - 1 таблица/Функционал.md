# Функционал модуля

Один способ хранения. Все справочники лежат в одной таблице секциями. Поля значения хранятся документом. История кода — несколько периодов в той же секции. Состав колонок живёт в версии: одновременно возможны черновик и активная версия.

Поиск состояния описан в [Поиск.md](Поиск.md). Актуальная строка читает активную версию. Черновик читается только с параметром `draft`.

| № | Функциональность | Описание |
| --- | --- | --- |
| 1 | Создание справочника | Администратор задаёт код, название, владельца и колонки. Создаётся паспорт, пустая секция и версия со статусом черновик. Активной версии нет, актуальное чтение не работает. |
| 2 | Редактирование метаданных | Название и владелец меняются сразу. Колонки — добавить, удалить, переименовать, сменить тип — пишутся в черновик. Если черновика ещё не было, он создаётся и не заменяет активную версию. Пока черновик не опубликован, актуальные запросы идут по прежней схеме |
| 3 | Деактивация справочника | Паспорт перестаёт быть активным. Секция и состояния остаются. В перечень для пользователя справочник больше не входит, значение по нему не читается, новое состояние не записывается. |
| 4 | Редактирование данных | Пока есть черновик, новое состояние кода пишется в него и не закрывает опубликованную строку. Без черновика прежняя открытая строка закрывается моментом начала новой. После смены типа затронутые коды записывают в черновик и проверяют чтением с `draft` |
| 5 | Публикация черновика | Черновик становится активной версией, прежняя активная закрывается. Черновые строки входят в период с момента публикации. После этого запросы без `draft` читают новую схему |

# Функции административной панели

| № | Экран | Что выводим | Действия пользователя |
| --- | --- | --- | --- |
| 1 | Каталог справочников | Код, название, владелец, состояние | Открыть справочник, создать новый, открыть паспорт, показать следующую страницу |
| 2 | Новый справочник | Название, код, владелец, колонки, признак колонки по умолчанию | Создать или вернуться без сохранения |
| 3 | Паспорт | Код, название, владелец, деактивация, версии: номер, статус, период, колонки | Сохранить название, владельца и колонки черновика, опубликовать черновик, деактивировать, открыть состояния |
| 4 | Состояния | Код, колонки выбранной версии, начало и конец. Открытые опубликованные, на момент или черновик | Записать состояние, сменить отбор, вернуться к паспорту |

# Функции пользователя

Клиент не выбирает таблицу и не передаёт устройство хранения. Сначала он узнаёт коды справочников и коды колонок, затем читает значение.

| № | Операция | Что получает | Как выбирает |
| --- | --- | --- | --- |
| 1 | Перечень справочников | Код и название справочников с активной версией | Страница перечня. Деактивированных и справочников только с черновиком в нём нет |
| 2 | Колонки справочника | Код, название, тип и признак колонки по умолчанию | Код справочника. Без параметра — активная версия. С параметром `draft` — черновик |
| 3 | Значение | Одна колонка или словарь колонок. Если состояния нет, приходит ответ без значений | Код справочника и код записи обязательны. Колонка необязательна. Без момента и без `draft` — открытое состояние активной версии: пока версии нет, запрос не выполняется. С `draft` — черновик. С моментом — опубликованное состояние на это время, черновик не читается |
