# Функционал администратора

| № | Функциональность | Описание |
| --- | --- | --- |
| 1 | Создание справочника | Администратор задаёт код, название, владельца и колонки. Создаётся паспорт, пустая секция и первая версия со статусом черновик. Активной версии нет, актуальное чтение не работает. |
| 2 | Создание черновика | Когда активная версия уже есть и черновика нет, открывается следующая версия. Её колонки копируются из активной. Второй черновик не создаётся |
| 3 | Редактирование метаданных черновика | Название и владелец паспорта меняются сразу и в версию не входят. Колонки — добавить, удалить, переименовать, сменить тип — заменяют состав существующего черновика. Если изменились состав, код или тип, уже записанные черновые строки удаляются |
| 4 | Перезаливка значений | После такого изменения колонок администратор заново записывает каждый открытый код полным набором новых колонок. Закрытые периоды не перезаливаются. Пока хотя бы у одного открытого кода нет полной черновой строки, черновик не публикуется |
| 5 | Публикация черновика | Черновик становится активной версией, прежняя активная закрывается. Черновые строки входят в период с момента публикации. Запросы без `draft` читают новую схему. Запрос с `draft` отвечает так же, как запрос версии, которой нет: черновика уже нет, активные данные вместо него не отдаются. Смена только подписи колонки или признака «по умолчанию» перезаливку не требует |
| 6 | Удаление черновика | Черновик и его строки удаляются, активная версия и опубликованные строки остаются. Пока активной версии нет, единственный черновик удалить нельзя |
| 7 | Деактивация справочника | Паспорт перестаёт быть активным. Секция и состояния остаются. В перечень для пользователя справочник больше не входит, значение по нему не читается, новое состояние не записывается. Черновик при этом открыть, изменить и удалить можно |
| 8 | Редактирование данных | Пока есть черновик, новое состояние кода пишется в него целиком и не закрывает опубликованную строку. Без черновика прежняя открытая строка закрывается моментом начала новой |
| 9 | Просмотр справочников | Администратор получает код, название, владельца и состояние, в том числе деактивированные справочники |
| 10 | Просмотр паспорта | Администратор получает паспорт и версии: номер, статус, период и колонки, включая черновик и закрытые |
| 11 | Просмотр состояний | Администратор читает открытые опубликованные строки, строки на момент или строки черновика. После публикации запрос черновика отвечает так же, как на отсутствующую версию |

# Функционал пользователя

| № | Функциональность | Описание |
| --- | --- | --- |
| 1 | Перечень справочников | Код и название справочников с активной версией. Деактивированных и справочников только с черновиком в перечне нет |
| 2 | Колонки справочника | Код, название, тип и признак колонки по умолчанию. Без параметра — активная версия. С параметром `draft` — черновик. После публикации черновика ответ тот же, что на отсутствующую версию |
| 3 | Значение | Одна колонка или словарь колонок. Код справочника и код записи обязательны. Колонка необязательна: пусто — колонка по умолчанию, одно или несколько имён — эти колонки. `attributes_all` запрашивает все колонки выбранной схемы и не передаётся вместе с именами. Без момента и без `draft` — открытое состояние активной версии: пока версии нет, запрос не выполняется. С `draft` — черновик, а если его уже опубликовали — тот же ответ, что на отсутствующую версию. С моментом — опубликованное состояние на это время. Если состояния нет, приходит ответ без значений |
