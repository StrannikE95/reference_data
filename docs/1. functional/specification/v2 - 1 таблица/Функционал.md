# Функционал администратора

| № | Функциональность | Описание |
| --- | --- | --- |
| 1 | Создание справочника | Администратор задаёт код, название, владельца и колонки. У колонки указано, обязательна она или нет. Справочник появляется как черновик метаданных. |
| 2 | Создание черновика | Черновик открывается только чтобы менять атрибуты действующего справочника. Для правки значений элементов он не создаётся. У 1 справочника может быть только 1 черновик. |
| 3 | Правка черновика | Название и владелец меняются сразу. В черновике меняется состав атрибутов: колонка добавляется, удаляется, переименовывается, меняет тип или обязательность. |
| 4 | Перезаливка справочника | Если состав атрибутов изменился, данные справочника загружаются заново. У каждого элемента заполнены обязательные атрибуты. Пустым может остаться только необязательный. Прошлые закрытые состояния не переписываются. |
| 5 | Публикация черновика | Черновик становится активной версией, прежняя активная закрывается. После смены состава атрибутов без перезаливки справочника черновик не публикуется. |
| 6 | Удаление черновика | Подготовленные изменения выбрасываются, действующий справочник остаётся. Черновик, который ещё ни разу не публиковали, удалить нельзя. |
| 7 | Деактивация | Справочник перестаёт отдаваться пользователям. Записанные данные сохраняются. |
| 8 | Правка данных | Администратор записывает новое состояние элемента сразу в действующий справочник. Черновик для этого не нужен. Обязательные атрибуты заполнены, необязательный можно оставить пустым. |
| 9 | Просмотр | Администратор видит список справочников, их паспорта и состояния: действующие, на выбранный момент и черновик. |

# Функционал пользователя

| № | Функциональность | Описание |
| --- | --- | --- |
| 1 | Перечень справочников | Пользователь видит действующие справочники. Выключенные и ещё не опубликованные в перечень не входят. |
| 2 | Колонки справочника | Пользователь видит колонки справочника: название, тип, какая колонка основная и какие атрибуты обязательны. Можно запросить колонки черновика. |
| 3 | Значение | Пользователь читает элемент справочника: одну колонку, несколько или все. Можно запросить черновик или состояние на выбранный момент. Если элемента нет, приходит пустой ответ. |
