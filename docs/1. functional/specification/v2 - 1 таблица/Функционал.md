# Функционал администратора

| № | Функциональность | Описание |
| --- | --- | --- |
| 1 | Создание справочника | Администратор задаёт код, название, владельца и колонки. У колонки указано, обязательна она или нет. Справочник появляется как черновик метаданных. |
| 2 | Создание черновика | Черновик открывается только чтобы менять атрибуты действующего справочника. Для правки значений элементов он не создаётся. У 1 справочника может быть только 1 черновик. Пока черновик открыт, новые состояния элементов пишутся в него, а действующий справочник не меняется. |
| 3 | Правка черновика | Название и владелец меняются сразу. В черновике меняется состав атрибутов: колонка добавляется, удаляется, переименовывается или меняет тип. Там же атрибут делают обязательным, снимают обязательность, меняют название колонки и то, какая колонка основная. |
| 4 | Перезаливка справочника | Если состав атрибутов изменился или атрибут стал обязательным, данные справочника загружаются заново. У каждого элемента заполнены обязательные атрибуты. Пустым может остаться только необязательный. Прошлые закрытые состояния не переписываются. Снятие обязательности, смена названия колонки и смена основной колонки перезаливку не требуют. |
| 5 | Публикация черновика | Черновик становится активной версией, прежняя активная закрывается. После смены состава атрибутов или после того, как атрибут стал обязательным, без перезаливки справочника черновик не публикуется. Паспорт показывает это, пока перезаливка не выполнена. Состояния из черновика публикуются с введённым началом, прежняя открытая строка закрывается этим началом. |
| 6 | Удаление черновика | Подготовленные изменения выбрасываются, действующий справочник остаётся. Черновик, который ещё ни разу не публиковали, удалить нельзя. |
| 7 | Деактивация | Справочник перестаёт отдаваться пользователям. Записанные данные сохраняются. |
| 8 | Правка данных | Черновик для правки значений не создаётся. Если черновик не открыт, администратор записывает новое состояние элемента сразу в действующий справочник. Если черновик уже открыт, состояние записывается в него: действующий справочник параллельно не меняется. Начало нового состояния строго позже начала открытого состояния этого кода, в том числе когда запись идёт в черновик. Обязательные атрибуты заполнены, необязательный можно оставить пустым. |
| 9 | Просмотр | Администратор видит список справочников, их паспорта и состояния: действующие, на выбранный момент и черновик. |

# Функционал пользователя

| № | Функциональность | Описание |
| --- | --- | --- |
| 1 | Перечень справочников | Пользователь видит действующие справочники. Выключенные и ещё не опубликованные в перечень не входят. |
| 2 | Колонки справочника | Пользователь видит колонки справочника: название, тип, какая колонка основная и какие атрибуты обязательны. Можно запросить колонки черновика. |
| 3 | Значение | Пользователь читает элемент справочника: одну колонку, несколько или все. Колонку указывают её текущим кодом, в том числе когда читают состояние на выбранный момент. Можно запросить черновик или состояние на выбранный момент. Если элемента нет, приходит пустой ответ. |
