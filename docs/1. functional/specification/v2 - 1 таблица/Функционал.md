# Функционал модуля

Один способ хранения. Все справочники лежат в одной таблице секциями. Поля значения хранятся документом. История кода — несколько периодов в той же секции. Номер редакции не используется.

Поиск состояния описан в [Поиск.md](Поиск.md). Актуальная строка и строка на момент выбираются одним правилом периода.

| № | Функциональность | Описание |
| --- | --- | --- |
| 1 | Создание справочника | Администратор задаёт код, название, владельца и колонки. Одна колонка отмечена как значение по умолчанию. Создаётся паспорт и пустая секция. Строк ещё нет. |
| 2 | Редактирование метаданных | Название, владелец и состав колонок. Справочник, в котором была колонка `name`, получает ещё `is_bearing` и `density`. Уже записанные документы не переписываются. |
| 3 | Деактивация справочника | Паспорт перестаёт быть активным. Секция и состояния остаются. В перечень для пользователя справочник больше не входит, значение по нему не читается, новое состояние не записывается. |
| 4 | Редактирование данных | Новое состояние кода: момент начала, код родителя и полный набор полей. Прежнее открытое состояние закрывается этим моментом. |

# Функции административной панели

| № | Экран | Что выводим | Действия пользователя |
| --- | --- | --- | --- |
| 1 | Каталог справочников | Код, название, владелец, состояние | Открыть справочник, создать новый, открыть паспорт, показать следующую страницу |
| 2 | Новый справочник | Название, код, владелец, колонки, признак колонки по умолчанию | Создать или вернуться без сохранения |
| 3 | Паспорт | Код, название, владелец, состояние, колонки | Сохранить название, владельца и состав колонок, деактивировать, открыть состояния |
| 4 | Состояния | Код, поля, родитель, начало и конец. Либо только открытые, либо на выбранный момент | Записать новое состояние, сменить отбор, вернуться к паспорту |

# Функции пользователя

Клиент не выбирает таблицу и не передаёт устройство хранения. Сначала он узнаёт коды справочников и коды колонок, затем читает значение.

| № | Операция | Что получает | Как выбирает |
| --- | --- | --- | --- |
| 1 | Перечень справочников | Код и название активных справочников | Страница перечня. Деактивированных в нём нет |
| 2 | Колонки справочника | Код, название, тип и признак колонки по умолчанию | Код справочника из перечня |
| 3 | Значение | Одна колонка или словарь колонок. Если состояния нет, приходит ответ без значений | Код справочника и код записи обязательны. Колонка необязательна: пусто — колонка по умолчанию, одно имя — эта колонка, несколько имён — словарь, `*` — все колонки словарём. Момент необязателен: пусто — открытое состояние, момент задан — состояние на это время |
