# Функционал модуля

Один способ хранения. Все справочники лежат в одной таблице секциями. Поля значения хранятся документом. История кода — несколько периодов в той же секции. Состав колонок живёт в версии: одновременно возможны черновик и активная версия.

Поиск состояния описан в [Поиск.md](Поиск.md). Актуальная строка читает активную версию. Черновик читается только с параметром `draft`.

| № | Функциональность | Описание |
| --- | --- | --- |
| 1 | Создание справочника | Администратор задаёт код, название, владельца и колонки. Создаётся паспорт, пустая секция и первая версия со статусом черновик. Активной версии нет, актуальное чтение не работает. |
| 2 | Создание черновика | Когда активная версия уже есть и черновика нет, открывается следующая версия. Её колонки копируются из активной. Второй черновик не создаётся |
| 3 | Редактирование метаданных черновика | Название и владелец паспорта меняются сразу и в версию не входят. Колонки — добавить, удалить, переименовать, сменить тип — заменяют состав существующего черновика. Если изменились состав, код или тип, уже записанные черновые строки удаляются |
| 4 | Перезаливка значений | После такого изменения колонок администратор заново записывает каждый открытый код полным набором новых колонок. Закрытые периоды не перезаливаются. Пока хотя бы у одного открытого кода нет полной черновой строки, черновик не публикуется |
| 5 | Публикация черновика | Черновик становится активной версией, прежняя активная закрывается. Черновые строки входят в период с момента публикации. Запросы без `draft` читают новую схему. Запрос с `draft` отвечает так же, как запрос версии, которой нет: черновика уже нет, активные данные вместо него не отдаются. Смена только подписи колонки или признака «по умолчанию» перезаливку не требует |
| 6 | Удаление черновика | Черновик и его строки удаляются, активная версия и опубликованные строки остаются. Пока активной версии нет, единственный черновик удалить нельзя |
| 7 | Деактивация справочника | Паспорт перестаёт быть активным. Секция и состояния остаются. В перечень для пользователя справочник больше не входит, значение по нему не читается, новое состояние не записывается. Черновик при этом открыть, изменить и удалить можно |
| 8 | Редактирование данных | Пока есть черновик, новое состояние кода пишется в него целиком и не закрывает опубликованную строку. Без черновика прежняя открытая строка закрывается моментом начала новой |

# Функции административной панели

| № | Экран | Что выводим | Действия пользователя |
| --- | --- | --- | --- |
| 1 | Каталог справочников | Код, название, владелец, состояние | Открыть справочник, создать новый, открыть паспорт, показать следующую страницу |
| 2 | Новый справочник | Название, код, владелец, колонки, признак колонки по умолчанию | Создать или вернуться без сохранения |
| 3 | Паспорт | Код, название, владелец, деактивация, версии: номер, статус, период, колонки | Сохранить название и владельца, создать черновик, сохранить колонки черновика, удалить черновик, опубликовать черновик, деактивировать, открыть состояния |
| 4 | Состояния | Код, колонки выбранной версии, начало и конец. Открытые опубликованные, на момент или черновик | Записать состояние, сменить отбор, вернуться к паспорту |

# Функции пользователя

Клиент не выбирает таблицу и не передаёт устройство хранения. Сначала он узнаёт коды справочников и коды колонок, затем читает значение.

| № | Операция | Что получает | Как выбирает |
| --- | --- | --- | --- |
| 1 | Перечень справочников | Код и название справочников с активной версией | Страница перечня. Деактивированных и справочников только с черновиком в нём нет |
| 2 | Колонки справочника | Код, название, тип и признак колонки по умолчанию | Код справочника. Без параметра — активная версия. С параметром `draft` — черновик. После публикации черновика такого запроса черновик уже нет, ответ тот же, что на отсутствующую версию |
| 3 | Значение | Одна колонка или словарь колонок. Если состояния нет, приходит ответ без значений | Код справочника и код записи обязательны. Колонка необязательна. Без момента и без `draft` — открытое состояние активной версии: пока версии нет, запрос не выполняется. С `draft` — черновик, а если его уже опубликовали — тот же ответ, что на отсутствующую версию. С моментом — опубликованное состояние на это время |
