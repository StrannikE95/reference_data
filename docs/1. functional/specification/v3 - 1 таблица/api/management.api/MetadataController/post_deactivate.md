# [На главную](../../../API.md)

# Описание

POST **/admin/dictionaries/{dictionary_code}/deactivate**
Поставить справочнику `inactive`. Строки значений остаются. Повторный вызов ничего не меняет.

# Входные параметры

+ `dictionary_code`:
    + path
    + Обязательно
    + `^[a-z][a-z0-9_]{0,62}$`

Тела нет.

# Поля ответа

+ `dictionary_code`
+ `status` = `inactive`

# Алгоритм работы

## Валидация

1. Проверить `dictionary_code`.
    + Нарушение:
        + Код: `invalid_request`
        + Статус: `400`
2. Найти паспорт по коду без учёта регистра.
    + Нет:
        + Код: `dictionary_not_found`
        + Статус: `404`

## Бизнес-логика

1. Если `status = inactive`, вернуть статус `200`.
2. Иначе записать `inactive`. Строки `dictionary_row` не трогать.
3. Вернуть статус `200`.

```mermaid
flowchart TD
  found{"Паспорт есть"} -->|нет| miss["404 dictionary_not_found"]
  found -->|да| off{"Уже inactive"}
  off -->|да| ok["200"]
  off -->|нет| save["UPDATE status"]
  save --> ok
```

Пользовательский каталог деактивированный справочник больше не показывает. Запись новых состояний этим вызовом не запрещается внутри него самого: её отклоняет запись состояния.
