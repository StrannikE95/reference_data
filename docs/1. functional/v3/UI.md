# UI администратора

Экраны администратора справочников. UI работает с простыми списками: у справочника одна таблица данных и версии этой таблицы.

## 1. Общие правила

- Справочник описывается полями «Код», «Название» и «Владелец».
- Владелец вводится при создании и показывается в списке и на экране версий. Изменение паспорта возможно в отдельном окне.
- Код после создания не редактируется. Название и владелец меняются в окне «Паспорт».
- Версия создаётся загрузкой CSV или JSON и остаётся черновиком. Пока черновик есть, вторая загрузка не принимается: его сначала удаляют.
- Публикация в одной транзакции делает черновик действующим и закрывает прежнюю действующую версию. Дату конца прежней версии ставит система.
- Закрытие без новой версии меняет статус только этой версии и выключает справочник для новых заявок. Дату конца вводят на экране.
- Архивация меняет статус только закрытой версии. «В архиве» — отдельный статус. Строки такой версии не ищутся.
- Даты на экранах показываются как `ДД.ММ.ГГГГ`.
- Ошибка показывается текстом сообщения.

### 1.1. Статусы версии

| Экран | Действия |
|---|---|
| Черновик | Опубликовать, Удалить, Найти |
| Действует | Найти, Закрыть |
| Закрыта | Найти, Архивировать |
| В архиве | Нет |

## 2. Экраны
## 2.1. Экран «Справочники»

[Пример экрана](ui/dictionaries.html)

### 2.1.1 Что отображается

| Колонка | Значение |
|---|---|
| Код | Код справочника |
| Название | Название справочника |
| Владелец | Владелец или «—» |
| Версия | Номер действующей версии или «—», если её нет |

Если справочников нет, показывается «Справочников пока нет».

### 2.1.2 Действия

- Выбрать строку — открыть экран версий.
- «Паспорт» — открыть окно изменения паспорта.
- «Создать новый справочник» — открыть форму нового справочника.
- «Загрузить ещё» — показать следующую страницу, если она есть.

## 2.2. Экран «Новый справочник»

[Пример экрана](ui/new-dictionary.html)

### 2.2.1. Что отображается

| Поле | Обязательно | Что вводится |
|---|---|---|
| Название | да | Название справочника |
| Код | да | Код справочника |
| Владелец | нет | Владелец |

Таблица дополнительных полей:

| Колонка | Что вводится |
|---|---|
| Тип | Строка, целое, большое целое, дата, UUID |
| Поле | Код поля |
| Название | Подпись поля |

Код значения и подпись в эту таблицу не добавляются. Они есть у каждой строки данных.

### 2.2.2. Действия

- «Добавить новое поле» — пустая строка.
- «Удалить» в строке — убрать поле до создания.
- «Создать» — создать справочник и пустую таблицу, перейти к версиям. Версии при этом ещё нет.
- «Отмена» — вернуться к списку без сохранения.

## 2.3. Экран «Версии справочника»

[Пример экрана](ui/versions.html)

### 2.3.1. Что отображается

Шапка: название, код, владелец или «—».

Таблица версий, сначала более новые:

| Колонка | Значение |
|---|---|
| № версии | Номер версии |
| Статус | «Черновик», «Действует», «Закрыта», «В архиве» |
| Дата С | Дата начала или «—» |
| Дата ПО | Дата конца или «—» |
| Действия | по таблице статусов |

### 2.3.2. Действия

- «Загрузить новую версию справочника» — диалог загрузки. Если черновик уже есть, файл не отправляется: у черновика остаётся «Удалить».
- «Паспорт» — открыть окно изменения паспорта.
- «Опубликовать» — только черновик. В одной транзакции он становится действующим, а прежняя действующая версия закрывается.
- «Закрыть» — только действующая версия. Диалог с датой конца. Меняется статус этой версии. Справочник перестаёт быть действующим для новых заявок. История остаётся.
- «Архивировать» — только закрытая версия, после подтверждения. Статус становится «В архиве». Поиск строк этой версии больше недоступен.
- «Удалить» — только черновик, после подтверждения. Версия и её строки удаляются.
- «Найти» — экран поиска строк этой версии. Для архива действие скрыто.
- «Отмена» — вернуться к списку справочников.

## 2.4. Окно «Паспорт»

[Пример экрана](ui/passport.html)

Открывается действием «Паспорт» из списка справочников или с экрана версий.

### 2.4.1. Что отображается

| Поле | Можно менять | Что показывается |
|---|---|---|
| Код | нет | Код справочника |
| Название | да | Название справочника |
| Владелец | да | Владелец или пусто |

### 2.4.2. Действия

- «Сохранить» — записать название и владельца. Код не меняется. Список и шапка версий показывают новые значения.
- «Отмена» — закрыть окно без сохранения.

## 2.5. Диалог «Загрузка новой версии»

[Пример экрана](ui/upload.html)

### 2.5.1. Что отображается

| Поле | Обязательно | Что вводится |
|---|---|---|
| Файл | да | CSV или JSON, не больше 100 МБ. В файле код значения, подпись и поля справочника |
| Дата начала действия | да | Дата, с которой версия действует |

### 2.5.2. Действия

- «Загрузить» — создать черновик.
- «Отмена» — закрыть диалог.
- После успеха диалог закрывается, список версий обновляется, у новой строки есть «Опубликовать» и «Удалить».
- Если черновик уже есть, показывается сообщение о конфликте. Новый черновик создаётся после «Удалить».

## 2.6. Экран «Данные версии»

[Пример экрана](ui/version-data.html)

Открывается действием «Найти» у черновика, действующей или закрытой версии.

### 2.6.1. Что отображается

Строка поиска и таблица найденных строк: код значения, подпись и дополнительные поля. Порядок по коду значения.

Пустой поиск показывает страницу всех строк версии. «Загрузить ещё» — если страница не последняя.

### 2.6.2. Действия

- Ввести текст и «Найти» — оставить строки, где код или подпись содержит этот текст.
- «Очистить» — снова показать страницу без фильтра.
- «Назад» — вернуться к версиям.
