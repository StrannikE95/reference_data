# Ссылка снаружи

+ Граница модуля уже такая: ссылку «объект → код» хранит владелец объекта, модуль справочников про эту ссылку ничего не знает. 
+ Поэтому декларативный FOREIGN KEY из доменной базы в базу справочников не появляется. Это не ограничение SQL, а разные базы и разный жизненный цикл

Use-case:
+ Варианты использования справочника клиентом:
    + Хранить «объект → код» : ссылка на объект актуальной версии. При обновлении его значения в новой версии справочника значение по ссылке тоже изменится (либо может вернуть ошибку, если элемент справочника был удален)
    + Хранить «объект → код → version_id» : ссылка на объект конкретной версии. При изменении справочника будет выпускаться новые версии объектов с новым version_id, поэтому значение по ссылке не изменится.

P.S. Длинный процесс должен копировать не справочник, а номер редакции справочника в момент старта (а лучше - только дату старта процесса - номер редакции разный у разных справочников и его можно получить 1 вызовом API)


# Поэлементная история


+ Ломающее изменение схемы по-прежнему новый справочник, как с КЛАДР на ФИАС.

На паспорте достаточно одного признака стратегии, Леша как раз просил хранить её в настройках справочника.
- **Снимок.** Материал стен и прочие короткие списки. Секция на редакцию, ссылка снаружи `(value_code, version_id)`, при публикации строки копируются только внутри справочника. Требование «старый контракт видит старый состав» уже закрыто. Требование «не перелинковывать внешние ссылки» тоже: снаружи нечего переписывать.
- **Интервал строки.** Длинный перечень с редкими правками. Копируется только изменённый код. Снаружи тот же код; номер редакции или дата выбирают интервал. Отдельный движок версий элемента не строится.

| value_code | name                | valid_from | valid_to   | Version_id |
| ---------- | ------------------- | ---------- | ---------- | ---------- |
| BRICK      | Кирпич              | 2024-01-01 | 2026-10-19 | 1          |
| BRICK      | Кирпич керамический | 2026-10-20 |            | 2          |
| WOOD       | Дерево              | 2024-01-01 |            | 1          |

- **Адреса и сотни гигабайт.** Не эта стратегия и не этот сервис: в границах модуля адресная запись туда целиком не входит.
